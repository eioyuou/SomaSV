# HG008 chr22 demo data

This folder contains demo BAM files for HG008 chromosome 22 data, including tumor and normal samples from different sequencing platforms and coverages.

## Files

- `HG008_30X_HiFi_chr22_tumor_demo.bam`
- `HG008_30X_HiFi_chr22_tumor_demo.bam.bai`
- `HG008_10X_HiFi_chr22_normal_demo.bam`
- `HG008_10X_HiFi_chr22_normal_demo.bam.bai`
- `HG008_30X_illumina_chr22_normal_demo.bam`
- `HG008_30X_illumina_chr22_normal_demo.bam.bai`

## Description

These files are small demo datasets prepared for visualization, testing, and method demonstration on chromosome 22.

- `HG008_30X_HiFi_chr22_tumor_demo.bam`  
  Tumor demo BAM from PacBio HiFi data at approximately 30X coverage.

- `HG008_10X_HiFi_chr22_normal_demo.bam`  
  Normal demo BAM from PacBio HiFi data at approximately 10X coverage.

- `HG008_30X_illumina_chr22_normal_demo.bam`  
  Normal demo BAM from Illumina data at approximately 30X coverage.

## Notes

- Reference genome: GRCh38
- Region: chromosome 22
- Sample: HG008
- Platforms: PacBio HiFi and Illumina
- Use case: demo data for method testing
- These files are intended for demonstration only and do not represent full datasets

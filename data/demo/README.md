# HG008 chr20 demo data

This folder contains demo BAM files and SomaSV output VCF files for HG008 chromosome 20 data, including tumor and normal samples from different sequencing platforms and coverages.

## Files

### BAM files

- `HG008_30X_HiFi_chr20_tumor_demo_subset.bam`
- `HG008_30X_HiFi_chr20_tumor_demo_subset.bam.bai`
- `HG008_10X_HiFi_chr20_normal_demo_subset.bam`
- `HG008_10X_HiFi_chr20_normal_demo_subset.bam.bai`
- `HG008_30X_illumina_chr20_normal_demo_subset.bam`
- `HG008_30X_illumina_chr20_normal_demo_subset.bam.bai`

### VCF files

- `filtered.only_long.somatic.vcf`
- `final_somatic_variants.vcf`

## Description

These files are small demo datasets prepared for visualization, testing, and method demonstration on chromosome 20.

### BAM files

- `HG008_30X_HiFi_chr20_tumor_demo_subset.bam`  
  Tumor demo BAM from PacBio HiFi data at approximately 30X coverage.

- `HG008_10X_HiFi_chr20_normal_demo_subset.bam`  
  Normal demo BAM from PacBio HiFi data at approximately 10X coverage.

- `HG008_30X_illumina_chr20_normal_demo_subset.bam`  
  Normal demo BAM from Illumina data at approximately 30X coverage.

### VCF files

- `filtered.only_long.somatic.vcf`  
  Intermediate somatic structural variant callset generated by SomaSV using long-read evidence.

- `final_somatic_variants.vcf`  
  Final somatic structural variant callset produced by SomaSV for this demo dataset.

## Notes

- Reference genome: GRCh38
- Region: chr20:38,000,000-41,000,000
- Sample: HG008
- Platforms: PacBio HiFi and Illumina
- Tool: SomaSV
- Use case: demo data for visualization, testing, and method demonstration
- These files are intended for demonstration only and do not represent full datasets
